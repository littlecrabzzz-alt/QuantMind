# 回测费用配置

用途：配置 Qlib A 股回测费用，解释当前实现而不是承诺券商实际收费。以实际账户交割单和交易规则校准；其他回测器可能采用不同口径。

## 参数与单位

实现：`backend/services/engine/qlib_app/schemas/backtest.py`、`utils/cn_exchange.py`。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `commission` | `0.00025` | 双边佣金比例（万 2.5） |
| `min_commission` | `5.0` | 单笔最低佣金，元 |
| `stamp_duty` | `0.0005` | 仅卖出，成交金额比例 |
| `transfer_fee` | `0.00001` | 当前代码仅对 SH 前缀证券收取的过户费比例 |
| `min_transfer_fee` | `0.01` | 收取过户费时的最低值，元 |
| `impact_cost_coefficient` | `0.0005` | 平方根冲击模型系数 |

`0.00025 = 0.025%`，不能填成 `0.025`。页面输入单位与请求体比例值应分别核对。Schema 另接受 `open_cost/close_cost` 到 `buy_cost/sell_cost` 的别名；它们不能替代确认最终进入 `CnExchange` 的分项配置。

## 当前计算

对正的成交金额 `V`：

```text
佣金 = max(V × commission, min_commission)
过户费 = max(V × transfer_fee, min_transfer_fee)  # 仅 stock_id 以 SH 开头
印花税 = V × stamp_duty                         # 仅卖出
冲击成本 = V × impact_cost_coefficient × sqrt(V / 当日市场成交额)
总费用 = 佣金 + 过户费 + 印花税 + 冲击成本
```

市场成交额不可用或非正时，当前实现不计冲击成本；这不表示市场冲击不存在。不能把固定费率示例当成全成本。

**实现边界：** 当前 `CnExchange` 只对 SH 收过户费，并不是“全市场过户费已统一”的实现。研究比较必须披露这一口径；本文不修改运行时收费逻辑。

## 数值例子

默认参数下，忽略冲击成本，SH 证券买入和卖出金额各为 100,000 元：买入佣金 25 + 过户费 1 = 26 元；卖出再加印花税 50，共 76 元；往返 102 元。

各为 10,000 元时最低佣金生效：买入 5.1 元、卖出 10.1 元，往返 15.2 元。SZ 证券当前实现不计上述 SH 过户费，不能直接套用这两个总数。

## 配置与结果核对

在回测中心按实际券商费率填写参数，保存请求和结果中的最终费用配置；逐笔检查成交额、费用、市场、方向和参与率。比较策略时固定费用与成交约束，并另做成本敏感性分析。

最低佣金会显著影响小额频繁调仓；过小持仓、缺失成交量或过高参与率都可能使表面回测收益失真。历史税率或券商政策发生变化时，固定默认值不等于按历史日期自动切换，需明确研究假设。
