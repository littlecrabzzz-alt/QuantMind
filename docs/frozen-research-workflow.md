# 冻结输入与自动对照研究

新增 `scripts/run_frozen_research.py`，在已有 API 基线旁提供独立的离线研究入口。复用 `train.load_data`、训练函数、Qlib 日线事件驱动策略及项目 `CnExchange`，不另写成交引擎，也不调用真实交易接口。产物保存为文件，暂不注册到平台数据库。

## 固定方案

配置位于 `config/research_controls_cn_l1.json`，在看到对照结果前确定：

- 训练 2023-01-03 至 2024-12-31，验证 2025-01-06 至 2025-03-31，比较期 2025-04-07 至 2025-06-30。该比较期此前已经查看过，标为 `development_comparison`，不是最终独立测试。
- 根据训练结束前60个交易日的成交额中位数选100只主板股票，至少40日有成交；使用训练期数据及当期 Qlib 可用范围，不按测试收益或测试期流动性选择。
- 八因子 LightGBM Top20 对比20日动量 Top20，二者使用相同的 `n_drop=5` 和股票池；另设整个可用股票池的等权组合。等权组持股数不同，用于理解广泛市场暴露，不能替代 Top20 单因子对照。
- 三组均使用1000万元、95%目标总仓位、每日决策、次交易日收盘成交，以及同一套佣金、最低佣金、印花税、过户费和冲击成本配置。

## 执行与留档

```bash
python3 scripts/run_frozen_research.py run --output results/frozen-controls-new
python3 scripts/run_frozen_research.py verify --output results/frozen-controls-new
```

也可以先执行 `freeze` 检查方案和文件清单，再对同一目录执行 `run`。默认使用正在运行的 QuantMind 容器的镜像 ID，也可以通过 `--image` 指定本地已有镜像；固定的是镜像内容 ID，不是可变标签。

1. 校验时间切分、目标周期及资金配置；复制因子、辅助价格、Qlib 数据、相关代码及配置。逐文件校验后，再检查整个复制期间源文件有无变化。复制未完成时不允许训练，也不覆盖残留快照。
2. 将快照只读挂载到 `/frozen`，只将新产物目录挂载为可写。研究容器关闭网络、根文件系统只读，不挂载实时数据目录、数据库或 Docker socket。使用4核、8GB内存，并固定镜像架构与 Python 哈希种子。
3. 每个信号日单独读取因子分区，只用该日特征和训练时确定的缺失值填充值推理；与批量分数逐条校验。Qlib 策略原生读取前一交易日信号，不再额外平移一次。
4. 执行三组对照，保存信号、净值、成交、持仓、模型及运行时版本。真实成交与策略预演分开记录，逐笔现金、逐日持仓市值与账户净值、净收益和费用任一不一致都会失败。指数比较以首笔建仓日收盘为起点；Qlib原生基准还包含前一晚收益，单独保留，不混用。
5. 结束后重新校验快照，全部检查通过才写 `completion.json`。恢复已完成实验会验证产物哈希并复用结果；失败重跑创建新 attempt，旧记录保留。退出容器也保留，便于检查。

同一实验目录只运行一个进程。修改数据、代码、配置或运行环境需要新实验目录；每份快照约3GB，预留额外输出空间。现有 `run_quant_baseline.py` 仍是原 API 流程，不会自动变成冻结执行模式。

清单中的 `source_commit` 是原工作区的基准提交；实际执行代码由复制的文件及其内容哈希确定，包含当时尚未提交的修改，不应只看 Git 提交号判断运行版本。

| 20日动量 Top20 | 2.0840% | -9.7817% | 384 |
| 同股票池等权 | 9.6253% | -3.7885% | 1,589 |

相同建仓起点的沪深300收益为9.6572%。模型相对单因子收益差11.6476个百分点；该短区间仅用于研究比较，不能推断长期稳定超额收益，也不能与此前不同股票池、资金和策略包装器的基线混比。

57个信号日、5,700条逐日独立推理与批量评分完全一致；三组逐笔现金和每日资产核对误差均为0。两次完整研究运行的模型文件和信号文件逐字节一致，组合收益在浮点精度范围内一致。

`results/frozen-controls-20260907/` 保留首次代码大小写匹配失败的记录；`results/frozen-controls-20260907-v2/` 保留中间完整结果；v3固定Python哈希种子、显式限制推理线程、增加每日资产核对，并将指数比较起点对齐首笔建仓日收盘。每版输入快照、日志和输出均保留。

测试覆盖源数据更新不会改变已冻结内容、篡改被拒绝、只读隔离挂载、切分重叠拒绝、未来流动性不影响股票池，以及现金和费用核对。指定 `/tmp` 工作目录避免测试误导入镜像中的旧 `/app/train.py`；实际研究容器使用冻结代码路径并检查训练模块来源。

## 限制与下一步

冻结文件并不能证明原始因子在历史时点已经可得，也没有解决退市样本、财务公告时点、ST规则和成交报价回退问题。当前限制主板股票是为了避免将固定9.5%的涨跌停近似用于创业板、科创板或北交所，主板历史规则仍需独立处理。

逐日重放验证的是冻结特征经过当前推理实现的一致性，尚不是平台在线推理服务、券商接口的验收。研究容器直接使用 Qlib 策略与 `CnExchange`，结果与上一轮平台策略包装器的收益不能直接混为一次实验。

后续优先审计事件驱动成交中的报价回退与历史交易规则，再做向量化引擎对账；冻结版本接入 API 时使用受控的数据版本 ID，而不是允许请求任意指定宿主机路径。
