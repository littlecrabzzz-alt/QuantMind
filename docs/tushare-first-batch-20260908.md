## 使用已保存数据

```bash
python3 scripts/tushare_intake.py read \
  --root /Users/lizeyu/Documents/ChatGPT/投资/QuantMind/logs/tushare-mirror \
  --release-id probe-aab8a026df944573aec4d7ab8681c1c3 \
```
