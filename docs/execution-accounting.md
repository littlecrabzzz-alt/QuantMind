# 回测成交与资金账务合同

用途：区分执行引擎、成交与估值价格，以及回测报告和批次风控的核对边界。规则以实际运行代码/镜像和资产合同为准，旧冻结实验不会自动获得当前源码修正。

## 先确定实际引擎

平台 API 的 `use_vectorized=true` 不是旧 `VectorizedBacktestEngine` 的直接开关。当前 `backend/services/engine/qlib_app/services/backtest_service_runtime.py` 按支持的指数股票池及 `ashare_lab_available()` 决定使用 ashare-lab，否则回到 Qlib step；日志记录实际模式与门禁。ashare-lab 路径声明次日开盘整手撮合，不能据请求字段或日志文案认定已与所有 step 规则等价，仍需固定版本逐项对照。

`backend/shared/vectorized_backtest/engine.py` 是可直接调用的近似诊断引擎，不由上述 API 路由启用。它使用分数股、比例费用和收盘调仓，不覆盖整手、最低佣金、分市场过户费、成交量冲击或开盘执行。不能用同为TopK、每日调仓等表面相同证明引擎等价，也不能把诊断收益当正式可交易收益。

该诊断引擎要求信号已按执行日滞后：当天先按收盘估值原持股，再卖出，按可用现金买入，当日扣费；无信号日继续持有。缺失/非正/无限报价可按历史有效价估值，不能成交。提供 `changes` 时缺失/无限涨跌幅阻止交易；完全省略表示没有启用涨跌停检查，不是检查通过。

## 资金与收益恒等式

Qlib 风格报告：

```text
return = 扣费前日收益率
cost = 当日费用 / 上日净值
cost_amount = 当日费用金额
account = 上日净值 × (1 + return − cost)
cash + value = account
净日收益 = return − cost
```

首次建仓费用必须计入回撤；Sharpe 使用净日收益的均值与标准差。逐笔核对现金、费用和数量，逐日核对持仓市值、净值与收益；账户记录相符不证明所有应有订单都被正确生成/成交。另需追踪信号 → 目标权重 → 订单 → 裁剪/拒绝原因 → 成交，尤其检查从已有持仓降至零风险是否真实卖出。

基准起点、总回报/价格指数、分红、资金流及费用需与组合一致。净值片段重新归一化不等于从新日期以现金启动；资金规模改变后整手、最低费用及成交约束需要重跑，不能线性缩放冒充可执行账户收益。

## CnExchange 报价边界

入口 `backend/services/engine/qlib_app/utils/cn_exchange.py`：`get_close/get_factor` 可作有限历史估值回退，默认回看10个自然日，由 `QLIB_QUOTE_FALLBACK_LOOKBACK_DAYS` 配置。`get_deal_price` 只取请求区间和买卖方向指定的价格，无效成交价不改用历史价或另一个价格字段；当前 close、volume、factor 必须有限且为正，并通过方向涨跌停检查才允许交易。无效数据阻止成交，不凭空清除已有持仓。

这不证明历史ST、上市初期、板块切换、精确涨跌停价格或长期停牌估值均已准确。股票、ETF和其他资产的费用、交易单位、权益与交易限制分别验收，不能默认共用股票近似规则。

## RiskGate 批次边界

`backend/services/trade/runner/risk_gate.py` 的批次过滤：

- 有限正价格/数量；已接受开仓累计预留同股票敞口，空头按绝对市值计；未成交平仓或反向开仓不提前释放容量。不原地修改传入信号字典。
- 只有显式 `SELL_TO_CLOSE/BUY_TO_CLOSE` 获得减仓豁免：不受开仓集中度或开仓换手同比缩减，但仍受单笔金额/价格偏离约束；平仓换手先占剩余开仓预算。
- 账户资产无效、回撤无效或触发限制时阻止开仓。兼容的旧 BUY/SELL 信号不能自动获得减仓豁免。

这不是完整下单风控，也不能据此宣称真实订单已接入同一门禁。调用链还须证明可平仓数量、可用资金、跨批次挂单预留、成交与重试状态；生产下单能力以实际接入链路的独立验收为准。

## 复核边界

离线复核可使用 `scripts/verify_agent_research.py` 从保存CSV重算；冻结输入与模型读取一致性见[冻结研究合同](frozen-research-workflow.md)。应固定输入、信号、执行代码/镜像、费用和预期结果，分别验证正常样本与无效价格/停牌/方向/批次边界，不用历史一次通过数替代当前回归。

账务通过只说明记录内部相符，不证明因子PIT、独立样本外收益、ETF适配、模拟盘或券商端验收。未完成项必须在研究结论中明确保留。
