# QuantDB PG 内存故障修复与云端恢复

2026-09-26 11:18 CST：云端 PG 与 Qlib 均已恢复到最新交易日 2026-09-24。代码提交 `7b5dcea5` 已合入、推送并对齐两端；只重启云端 `quantmind`、`celery-worker`，健康检查通过。Mac 的活动研究未重启。

## 故障与改动

凌晨同步进入 PG 阶段后，1.5 GiB 容器内的 Celery 子进程被 OOM 杀死，后续 Qlib 阶段没有执行。旧 PG 转换会为全市场的 160 日回看窗口构造一个大 DataFrame，并挂载不相关的全历史视图。

现有 `fill_pg_from_parquet` 改为只扫描所需分区，复用 Qlib 的 256 MB / 单线程 DuckDB 配置与逐标的流式读取。价格指标保留原有前复权计算和 160 日预热；非价格字段只关联输出日期。PG 每批日期使用一个事务，分页 upsert，中途失败整批回滚；结束后关闭连接并释放临时文件。定时同步、管理台和本地刷新共用该入口，无新增采集系统或依赖。
