# 量化研究方法更新工作流

日期：2026-09-05。状态：已手动跑通公开来源采集，并创建启用 Codex 定时任务；首次定时触发尚待验证。

## 已确认

- 每日跨平台发现新的量化论文、方法、复现代码和技术讨论，用于研究、学习与实盘工程优化。
- 不处理市场新闻、个股利好利空、行情解读、情绪分析或交易推荐。
- 每条信息保留原始来源；论文结果、社区观点、系统推断、本地复现结论分别标记。

## 工作假设与待确定

- 当前采用 Codex 在本任务内定时运行本地采集脚本，并整理研究卡；未来如需脱离桌面应用常驻运行，可迁移至项目服务器上的 Celery。
- 已配置北京时间每天 15:00 运行，包括周末。
- 首次回看最近 7 天建立基线；之后按每个来源最后成功时间增量采集，并保留 72 小时重叠窗口。
- 每日推荐最多 5 条，没有足够相关内容时允许 0 条；其余合格条目保存供检索。
- 第一版可先输出研究清单和 Markdown 摘要，页面设计、外部消息渠道及部署目标另行确定。

## 每日处理流程

1. 读取来源配置及各自最后成功采集时间。按源限制请求量、超时和重试；单源失败不阻塞其余来源。
2. 获取标题、摘要/可访问正文、作者、首次发布时间、更新时间、原始 URL、论文标识和代码链接。
3. 以 arXiv ID、DOI、GitHub 发布 ID、规范化 URL 去重。跨平台转载合并来源；内容或版本变化保留修订记录。
4. 同时记录 `published_at`、`updated_at`、`first_seen_at` 和 `fetched_at`。首次发现旧文章标为历史补录，不能写成新论文。
5. 过滤市场新闻、推广、收益截图及缺少方法细节的讨论。低相关内容不进入推荐。
6. 按研究主题归类：数据与因子、预测模型、统计验证、组合与风险、交易执行、AI 研究工具。
7. 生成有原文依据的研究卡；只看过摘要就标明摘要级评估，不能声称已经读过全文或复现。
8. 根据与 QuantMind 的关联、证据充分程度、数据可获得性、复现成本和相对已收录材料的新意选择最多 5 条。
9. 保存全部合格条目和当日摘要。只推进成功来源的采集游标；记录部分失败、重复数和过滤数。

## 研究卡字段

- 原文标题、中文标题、作者、来源、原始链接、代码链接。
- 首次发表日期、更新日期、本地发现日期、版本。
- 类型：新论文 / 重要修订 / 方法文章 / 复现 / 工具发布 / 技术讨论。
- 它解决的问题、新方法、相对基线的变化。
- 证据：市场、样本区间、比较基线、成本处理、样本外测试；原文没说明的字段明确记为未知。
- 阅读深度与证据阶段：仅元数据 / 摘要 / 全文；原文报告 / 第三方复现 / 本地复现。
- 与 QuantMind 的关联模块、适用条件、局限和数据要求。
- 一个最小可检验实验及其失败条件；研究条目不会自动触发代码执行、模型替换或交易。
- 学习状态：待阅读 / 已阅读 / 候选实验 / 复现中 / 已验证 / 未复现成功 / 暂不采用。

## 日报样式

每条用短卡片展示“新内容是什么 → 为什么值得看 → 对项目哪里有用 → 怎么做最小验证 → 原文/代码”。顶部给出各平台采集状态；推荐数允许为零。不得把全部来源失败写成“无新方法”。

## 鉴权与密钥

- 本轮成功来源均未发送 API Token、账号密码或登录 Cookie。
- GitHub 公共 REST API 无鉴权额度通常为每个来源 IP 每小时 60 次；扩大监控范围时可增加只读 Token。本脚本当前不读取 Token。文档：https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api 。
- arXiv Atom 不需要 Key；历史补采需要遵守 API 访问节奏并处理 429，不能靠反复重试解决。
- 公开论坛访问和结构化解析是两个问题；动态页面、地区限制、登录限制应分别核验。聚宽尚未确定稳定采集路径，未要求用户提供密钥。
- 若增加自动中文方法解读与项目适用性分析，需要接入所选 LLM 的 API 配置；本次关键词初筛与采集无需模型费用。

## 已启用的 Codex 定时任务

- 名称：量化论文与研究方法日报。
- 创建工具返回的任务 ID：`automation`；状态：ACTIVE。
- 运行时间：北京时间每天 15:00，包括周末。
- 运行方式：回到当前 Codex 任务，执行 `python3 scripts/research_watch.py`，读取该次运行生成的 `report.json`，由 Codex 核对原文并整理最多 5 条中文研究卡。
- 输出：本次运行目录的 `digest.md`；使用 `data/research_watch/digest_state.json` 维护已评审/已报告内容及来源状态。首次调度执行时初始化该文件。
- 有值得读的新方法、重要修订或新的实质故障时在当前任务报告；没有可行动更新时保持安静。长期不变的已知聚宽解析限制不重复提醒。
- 不另行调用 DeepSeek 或其他付费模型 API；内容整理在 Codex 任务中完成。外部资料仅供研究，不自动执行第三方代码或触发交易。
- 本地任务依赖这台 Mac 开机、联网、保持可运行状态，Codex 应用运行且项目文件可访问。它不是已部署到服务器的常驻采集服务。
- 已确认任务创建成功并回读任务卡片；这是配置验证，不代表首次定时运行已经完成。
