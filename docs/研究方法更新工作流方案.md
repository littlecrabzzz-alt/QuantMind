# 研究资料采集与评审

用途：运行现有公开来源快照采集、核对部分失败，并把读过的资料转为可证伪课题。本文是操作指南，不是自动研究/日报服务已部署的声明。研究Agent入口见[工作台](research-workbench-operations.md)，课题登记见[案例流程](research-case-workflow.md)。

## 采集与离线重放

`scripts/research_watch.py` 需要 Python 3.10+、curl 和 POSIX 文件锁，不调用模型、不读取API key，也不执行第三方代码。以下第一条会联网，只在需要实际采集时执行：

```bash
python3 scripts/research_watch.py --lookback-days 7
# 解析已有原始快照，不联网；输出选择独立目录，避免改变日常目录中的去重数据库。
python3 scripts/research_watch.py --replay <既有运行目录> --output <本次独立输出目录>
```

默认输出根 `data/research_watch`，每次创建时间戳目录，保存 `raw/`、`report.json`、`report.md`；根目录 `catalog.sqlite3` 的 `entries/versions` 记录身份、指纹与修订。相同输出根有互斥锁，不并发重开采集器。

`--lookback-days` 可选1–365，包含今天在内的自然日；只控制候选筛选，不承诺补齐整个窗口。`--replay` 沿用原报告起止日，不按今天重算旧文新旧；重放保留原失败来源，退出码2仍可能是原来的部分失败。

## 当前来源与覆盖限制

| 来源 | 实际范围 |
| --- | --- |
| arXiv q-fin.ST/PM/TR/CP Atom | 当前公告批次，不保证完整回看；区分Feed生成时间、首次发表与修订 |
| Qlib / RD-Agent GitHub Releases | 各最多最近10个正式发布，不是全提交历史 |
| QuantsPlaybook Commits | 最多最近10个提交，不自动运行代码 |
| VeighNa / QuantConnect | 公开首页快照；无准确日期或时区时保持未知 |
| 聚宽 | 探测公开页是否有可解析条目，动态页面外壳不算成功 |

身份/内容指纹去重与版本记录已存在，但没有全量分页、逐源增量补采、漏跑恢复或跨平台DOI合并。限流、动态页面和地域/登录限制是不同问题，不能把解析失败直接当作缺密钥。单源失败保留其他来源结果，退出码2明确部分失败；全源失败不能写“今天没有新方法”。

脚本没有常驻调度、项目API或前端发布入口。历史桌面自动化任务的创建记录不证明它目前启用、首次触发成功或能够在Mac睡眠时运行；需要定时能力时另核对真实调度，不把旧配置当当前服务。

## 评审和研究卡

报告只做主题/日期初筛，不自动完成中文深读或收益验证。只保留有方法、代码、数据或实验细节的材料，排除市场新闻、推广和收益截图；推荐最多5条，可以为0。原始来源、版本、阅读与报告状态可保存在 `digest_state.json`，脚本采集不代替人工评审。

每条进入课题前记录：

1. 原始链接、作者、版本、首次发表/更新/本地发现日期；旧文首次发现或修订不能冒充新论文。
2. 阅读深度：元数据、摘要还是全文；证据是作者报告、第三方复现还是本地复现。未读部分和未知字段明确保留。
3. 问题、方法相对简单基线的变化、样本/成本/执行口径、限制与所需数据。
4. 一个最小可证伪实验及停止条件；来源阅读不自动启动计算、替换模型或授权交易。

## 可复用的方法评审门槛

这些是评审准则，不表示以下统计方法或访问控制已经实现：

- **反馈隔离**：训练、早停、搜索反馈与最终验证分开；全部失败/拒绝候选也留痕。最近半年保留和已查看区间用途按[冻结合同](frozen-research-workflow.md)执行，文件名叫test不恢复独立性。
- **完整候选族**：不能只保留最好的几条结果。在同一所谓样本外期反复选择已经使用了该数据；SPA/MCS等联合检验也不能修复前视、错误成交或缺失试验记录。打乱日收益再比较最终累计收益无效：`∏(1+r)` 与排列顺序无关。
- **成本后增量**：固定信号、日期、股票池、资金、实际仓位与成本再比较；因子分数相关、IC相关和执行后PnL相关是不同对象。空仓、缺失收益填零或不等风险不能冒充分散改善。
- **可得时点**：财报期末不是公告日，最新修订值不等于历史可用值；ROE、毛利/资产、应计利润代理有不同字段合同，不能只按名称替代。
- **实际执行**：目标权重变了不等于订单成交；核对目标—订单—成交和零仓位退出。ETF费率、申报单位与权益按资产合同，不默认套股票规则。
- **谨慎解释**：文献收益不转移为本项目收益；统计不显著允许结论为证据不足，复杂模型或更高毛收益不自动产生净经济价值。

评审通过后才登记来源、固定合同、核验数据并执行实验；研究阅读、输入完整性、开发比较、独立验证与交易准入是不同阶段。采集代码变更的离线自检入口为 `python3 scripts/research_watch.py --self-test`，不能代替真实来源/调度验收。
