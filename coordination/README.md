# 任务记录

2026-10-16 起远端开发已退役，本地为唯一开发源。本目录保留历史证据及仍在进行的本地长期任务记录，不再承担双端同步、预检或换端交接。

普通开发无需读取本目录或新建记录。仅在接续具体任务、查证历史、长期研究或重要数据操作时，读取相关主题的必要记录；旧记录中的命令和状态不代表现行规范，当前规则见 [AGENTS.md](../AGENTS.md)。

## 仍需记录时

- 复用已有主题；本地研究循环可继续使用现有 start/done 记录，不因本次整理中断或重命名。
- 新记录使用唯一文件名，例如 `<UTC时间>-mac-<任务标识>-<随机后缀>.md`；写增量，引用被接续或更正的记录，不争写一个 `CURRENT.md`。
- 只写负责范围、本次变化、验证及未验证项、输入/产物位置和下一步；代码交接再补分支、worktree、提交或补丁，不要求凑模板。
- 不复制大段日志，不记录凭据。历史记录不批量删除，也不作为恢复旧双端流程的授权。

独立 worktree 需要共享记录时，用 `git rev-parse --path-format=absolute --git-common-dir` 定位本机主工作树，将记录写入其 `coordination/<主题>/`，避免写进旧副本。
