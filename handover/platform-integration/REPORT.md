## 验证结果

- 公共执行/H2 回归：55 passed；历史/虚拟同逻辑逐日相等，恢复不重置，重复执行不重成交，超决策时限拒绝，日历扩展/篡改拒绝，隔夜记账完成后继续决策。
- Engine 容器内比较权限测试：1 passed。使用结果的所属用户校验；伪造配置中的 user_id 无法授权。
- TypeScript typecheck 和 Vite production build 退出码 0；只有既有大 chunk 提示。
- API 九组检查通过：幂等、冲突、保留段拒绝、版本归属、未回测 B 拒绝冻结、匿名/伪造身份拒绝、源码50份对值、历史策略过滤、工程归档。
- 页面在原端口 13001 验证：策略 v4/原件；回测现金/持仓/风险/曲线与指标；97.56% 对 87.60% 对比；页面复跑；账户停止/恢复；首页监控；研究结论与工程分类。窄屏账户页也已核对。
- 自有 Engine/worker 重启后冻结版本、完成结果及账户仍能读取，独立 H1/main/PG/Redis 未重启。worker 并发2，输入构建不独占执行槽。

验证过程中修复了：旧对比接口误从 config 取用户、pending 记录结果为空、运行态缓存过期前不更新、登录解码口径差异、前沿日历不足、隔夜补记账依赖、旧重复 pipeline 方法、虚拟页空值语义及研究证据默认展开。研究/执行指纹变化时重新发布版本，旧证据不被冒充成新版本。
